## 1.0.0 - 2026-10-20

Initial finalized publication package. The issue date is the document/package date; GitHub records the actual publication date when the release is published.

### Included

- Three unique supplied corporate raster originals, preserved byte-for-byte.
- Six icon exports and two background-composited PNG exports, with upscaling identified.
- The v1.0.0 digital documentation palette, typography, logo spacing and size standards.
- Company, product, rights, trademark, authorization and governance documentation.
- Illustrated brand handbook, reusable operational forms and publishing instructions.
- Asset/source inventories, duplicate-upload provenance, SHA-256 records and offline verification tools.

### Scope decisions

The duplicate transparent upload is recorded as the same asset rather than published as another variant. Native vector artwork, monochrome artwork, an editable wordmark and separately designated product logos are not part of this release. Corporate assets are not relabeled as BLT artwork.

The prior review edition is superseded by these final documents. This change does not create an ownership certificate, backdate an approval or assert a GitHub publication event.

The current domain is bluelinkos.com. The SolidProof profile's older-domain link is recorded as an external reference discrepancy, not silently treated as current. Company-supplied GitHub/contract references remain distinguishable from independently checked audit scope.
